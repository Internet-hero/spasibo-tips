# Ответы команде — кейс 3

## 1. Репозиторий и документы

- Репозиторий: https://github.com/Internet-hero/spasibo-tips
- Работаем в ветке `team_case_3`; `main` не изменяем.
- Да, документы ТЗ (`02_правила`, `03_data_dictionary`, `11_ИБ`) и README можно править, чтобы они соответствовали фактической реализации.

## 2. Комплект сдачи

Папка `case_3_tips` содержит заполненные `02`, `03`, `04`, `05`, `06_приложение`, `08`, `09`, `11`, CSV, рабочий CLI-прототип, draw.io-схемы и evidence-файлы. Архив: `case_3_tips.zip`.

Сдаём:

1. Код веб-приложения и ссылку на репозиторий.
2. Презентацию по шаблону.
3. Заполненное приложение и исходники draw.io.
4. Рабочий прототип `04_прототип.py` — включаем, поскольку он входит в материалы кейса и подтверждает проверку HMAC/сценариев.
5. ZIP папки `case_3_tips`.

## 3. Лимит чаевых

**Лимит 50 % возвращаем и оставляем**, поскольку он прямо указан в ТЗ. В интерфейсе сумма выше лимита автоматически заменяется на 50 % без ошибки. После успешной оплаты открывается форма с предложением написать, что именно понравилось. Доменная проверка отклоняет попытки передать значение выше 50 % напрямую.

## 4. Деплой и LMS

- Демо сейчас запускается локально через `npm install && npm run dev`; production-проверка — `npm run build && npm run preview`.
- Публичный деплой не выполнялся. Для статического демо подойдут GitHub Pages, Netlify или Vercel; перед публикацией нужно отдельно настроить хостинг.
- В LMS я ничего не загружал и не имею доступа к статусу LMS. Владельцу LMS нужно отметить фактически загруженные файлы самостоятельно.
