**Вход:** тот же `idempotency_key` дважды.  
**Ожидание:** тот же `payment_id`, одна новая запись платежа.  
**Факт:** возвращён исходный `payment_id`; повторный вызов не изменил состояние.  
**Пройден:** [x] да [ ] нет

## T3-5. Отмена
**Вход:** создать платёж и отменить до подтверждения.  
**Ожидание:** `CANCELED`; отмена из `PENDING` → 409.  
**Факт:** `CREATED → CANCELED`; отмена из `PENDING` возвращает `CANCEL_NOT_ALLOWED`, HTTP 409.  
**Пройден:** [x] да [ ] нет

## Дополнительная проверка лимита

При `base=637` и вводе 700 ₽ интерфейс устанавливает `tip=318.50` (50 %), `amount_total=955.50`; после `SUCCESS` автоматически открывается форма отзыва. Прямой вызов создания платежа с `tip_pct>50` отклоняется с `TIP_OUT_OF_RANGE`.
