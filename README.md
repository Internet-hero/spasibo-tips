# «Спасибо» — демо онлайн-чаевых

Адаптивный сервис по ТЗ v0.3: QR стола/заведения/сотрудника, выбор получателя, цели смены, анонимность, послания до 140 символов, мок-касса, сплит компанией, стена с TV-режимом, кабинеты сотрудника/управляющего/администратора, CRUD команды, графики, CSV и PNG QR.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`; локальная проверка сборки: `npm run preview`.

## Демо

- Быстрый вход в роли доступен на главной и `/login`.
- Сотрудник: `anna@spasibo.demo` / `demo`; код `ANNA2026`.
- Управляющий: `manager@spasibo.demo` / `demo`.
- Администратор: `admin@spasibo.demo` / `demo`.
- QR стола: `/p/table7/select`; личный QR Анны: `/p/anna`.
- Любая тестовая карта завершается успехом; номер с окончанием `0000` проверяет ошибку.

Это статическое хакатон-демо. Состояние хранится в `localStorage` текущего браузера и синхронизируется между его вкладками. Нет серверной БД, JWT, реальных платежей и синхронизации между разными устройствами; для production нужен API по разделу 6 ТЗ. Данные можно вернуть кнопкой «Сбросить демо».

## Проверки

```bash
npm test          # модульные инварианты
npm run test:e2e # Chromium: сценарии и 375/768/1024/1440 px
npm run lint
npm run build
```

Для первого E2E-запуска: `npx playwright install chromium`.
